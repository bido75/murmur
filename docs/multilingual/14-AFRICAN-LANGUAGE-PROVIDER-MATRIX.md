## African language support — what is actually known

### Translation (LLM-based)

- **Mechanism verified:** the provider translated English → Twi correctly in a live call (2026-10-30). The same call path serves every registry language.
- **Per-language quality: UNVERIFIED.** An LLM "supports" a language only in the sense that it will produce output. For high-resource languages (Swahili, Yoruba, Hausa, Amharic, Arabic) quality is expected to be solid but must be measured. For low-resource Ghanaian languages (Dagbani, Dangme, Dagaare, Kasem, Kusaal, Gurene, Mampruli, Gonja, Nzema) output may be poor — which is why they are tiered **experimental**.
- **Registry enforcement:** experimental languages are labeled "(experimental)" in the UI and are never marked transcription-capable (asserted by `src/lib/languages.test.ts`).

### Transcription (STT)

- **Per-language African support: UNVERIFIED.** The provider's official supported-language list has not yet been checked against the registry. Planned verification: fetch Mistral's Voxtral language documentation and Deepgram nova-3's language list, cross-check against the registry's African entries, and record results in this matrix.
- **Expected reality (to be confirmed, not claimed):** major languages (Swahili, Arabic, Hausa, Amharic, Yoruba) are commonly supported by commercial STT; most Ghanaian languages (Twi, Ewe, Ga, Dagbani…) are typically **not** in commercial STT lists. The registry already reflects this asymmetry honestly: only the 31-entry STT list carries `transcription: true`.
- **If a language has no STT support:** it stays visible with translation-only capability, and the research backlog records candidate paths (open-source ASR models such as Whisper fine-tunes for specific languages, community models on Hugging Face) with licensing notes — per the block-20 instruction to check alternatives rather than silently drop languages.

## Cost and safety controls (per block-19 Phase 4)

- Provider credentials server-side only.
- Chunked requests (≤120 lines / ~12k chars) bound per-call size.
- Structured tool output with a line-count invariant; wrong-count chunks keep originals (no content loss).
- Per-language capability gates (registry tiers) prevent advertising untested quality; per-language cost tracking is on the roadmap with the capability-matrix script.
